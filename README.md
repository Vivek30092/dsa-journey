## 📖 About

This repository is my personal DSA (Data Structures & Algorithms) practice log. Every file represents a concept learned, a problem solved, or a task completed while following the **Apna College DSA series** in **C++**. The goal is to go from basics to advanced — consistently, daily.

## 📂 File Naming Convention

```
{lecture}.{sub}_{topic}.cpp          — Concept / theory file
{lecture}.{sub}_LC{#}_{topic}.cpp    — LeetCode problem file
```

| Part | Meaning | Example |
|------|---------|---------|
| `lecture` | Apna College lecture number | `18` |
| `sub` | Sub-file index within a lecture | `0`, `1`, `2` |
| `LC{#}` | LeetCode problem number (if applicable) | `LC33` |
| `topic` | Short camelCase description | `rotatedSortedArray` |

**Examples:**
- `18.0_LC33_rotatedSortedArray.cpp` → Lecture 18, file 0, LeetCode #33
- `24.0_bubbleSort.cpp` → Lecture 24, file 0, concept (no LeetCode)
- `00.0_LC66_plusOne.cpp` → Extra LeetCode problem (not lecture-specific)

> Files sort chronologically by lecture number in your file explorer ✅
